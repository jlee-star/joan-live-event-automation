# Hackathon Project: Automating My Online Event Producer Script

For my Hackathon project, I explored how AI and automation could simplify my daily work as an Online Event Producer.

I used AI prompting, O'Reilly Expert Intelligence, VS Code, and Google Apps Script to create an automation that pulls course information from Google Sheets and generates a new facilitator script in Google Docs.

The automation runs daily and helps reduce manual copying and pasting while improving accuracy.

My biggest takeaway: AI drafts and I judge.
